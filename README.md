## 📌 Sobre o projeto

O **Livraria Lisboa** é um projeto de **UI/UX Design** desenvolvido no Figma com o objetivo de criar uma experiência completa de compra de livros através de uma interface mobile.

O projeto simula uma aplicação de e-commerce, contemplando diferentes etapas da jornada do usuário, desde o **cadastro e descoberta de produtos** até o **checkout, pagamento e acompanhamento de pedidos**.

Além da experiência de compra, o aplicativo também conta com recursos relacionados a **favoritos, avaliações, histórico de compras, notificações, perfil do usuário e suporte**.

O projeto está atualmente **em desenvolvimento**, sendo construído e refinado progressivamente no Figma.

# 🧠 UX Design

O projeto não está focado apenas na aparência das telas, mas também na forma como o usuário interage com o aplicativo.

### Principais pontos trabalhados

**Hierarquia de informações**

As informações são organizadas de acordo com sua importância para facilitar a leitura e compreensão.

**Navegação**

O usuário deve conseguir compreender onde está e para onde pode ir dentro do aplicativo.

**Ações principais**

As ações mais importantes, como **Comprar agora** e **Adicionar ao carrinho**, recebem destaque visual.

**Feedback**

O aplicativo possui telas e estados destinados a informar o usuário sobre ações realizadas, como pagamentos e confirmações.

**Jornada de compra**

O fluxo principal foi pensado de maneira contínua:

```text
Descoberta
    ↓
Pesquisa
    ↓
Produto
    ↓
Carrinho
    ↓
Entrega
    ↓
Pagamento
    ↓
Confirmação
    ↓
Acompanhamento
```
