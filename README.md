## 📖 Sobre o projeto

**Livraria Lisboa** é um projeto de **UI/UX Design** desenvolvido no Figma com o objetivo de criar uma experiência de compra de livros em uma aplicação mobile.

A proposta é desenvolver uma jornada de usuário completa, desde a descoberta de livros e navegação pelo catálogo até o processo de compra, pagamento e confirmação.

O projeto está sendo desenvolvido de forma progressiva, permitindo aplicar conceitos de **arquitetura da informação, hierarquia visual, navegação, prototipação e experiência do usuário**.

> 🚧 **Status:** O projeto ainda está em desenvolvimento e novas telas e funcionalidades serão adicionadas ao longo do processo.

# 🧠 UX Design

O projeto considera não apenas a aparência das telas, mas também a experiência do usuário durante a navegação.

### Hierarquia visual

Organização das informações de acordo com sua importância, facilitando a leitura e compreensão do conteúdo.

### Navegação

Construção de um fluxo que permita ao usuário compreender sua localização dentro do aplicativo e acessar as diferentes áreas de forma intuitiva.

### Ações principais

Destaque para ações importantes, como:

- **Comprar agora**
- **Adicionar ao carrinho**
- **Continuar para pagamento**
- **Finalizar compra**

### Feedback

Criação de telas de retorno para informar o usuário sobre ações importantes, especialmente durante o processo de pagamento.

### Jornada de compra

O fluxo principal foi estruturado para acompanhar o usuário desde a descoberta de um livro até a confirmação da compra.
